# Gifu University Digital Criation Club

Gifu University Digital Criation Club は、岐阜大学のデジタル創作同好会のGitHub Organizationです。

このOrganizationでは、Unity、Web、Python、Node.js、デザイン、3D、映像、音楽制作に関するプロジェクト、テンプレート、運用ドキュメントを管理します。

## 活動領域

- ゲーム制作
- Web制作
- ツール開発
- Discord Bot 開発
- UIデザイン
- 3D制作
- 映像制作
- BGM、SE、音楽制作
- 初心者向け学習と共同制作

## 参加方針

新入生やGitHub初心者も参加しやすいように、Issue、Pull Request、README、テンプレートを整備します。

Organization名は GitHub上の正式表記である `Gifu-University-Digital-Criation-Club` を使用します。
